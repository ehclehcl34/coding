## 3.7.0 — 팀 테두리 / 덱 10개 / 카드 아이콘 / 탑뷰 이동
- **팀 색 테두리**: 소환한 유닛·건물 모델 테두리가 팀 색(파랑/빨강)으로 빛남. 벽 너머로도 보임. 끄기: `game.team-glow: false`
  - 마크 발광은 보는 사람별로 다르게 할 수 없어서, 상대 유닛도 상대 팀 색으로 빛남
- **덱 10개**: 덱 화면 ◀ ▶ 로 덱 바꾸기 + **📖 덱 불러오기** 메뉴
  - 클릭: 그 덱 사용 (경기 전 덱 고르기 화면에서는 저장된 덱을 이번 판 덱으로 불러옴)
  - Shift+클릭: 지금 덱을 그 칸에 저장 (복사)
  - 기존 덱 1~3은 그대로 유지
- **카드 아이콘**: 실제 클래시 로얄 카드 일러스트(128x128) + 엘릭서 배지, 엘릭서 부족할 때는 흑백 (`preview/card_icons_3.7.0.png`)
- **탑뷰 앞뒤 이동**: 높이·좌우는 고정, WASD 로 경기장 앞뒤 이동 (`game.top-view.scroll`, 기본 30블록, 0 이면 예전처럼 고정)
- **프린세스 타워 복구**: 3.6.0 에서 프린세스 카드 모델이 타워 모델(clash_princess)을 덮어써서 타워가 사라졌던 버그 수정. 타워 몸체 `clash_princess_tower` + 꼭대기 프린세스 `clash_princess_top` 을 따로 띄움 → **타워는 가만히, 프린세스만 적 쪽으로 몸을 돌려 활을 쏨**. 예전 config 의 `clash_princess` 도 자동으로 새 타워로 바꿔 씀
- **크기 키움**: 엘릭서 골렘 1.8배, 대포 카트 1.8배(대포만큼), 바바리안 오두막·벌룬 1.5배, 고블린 오두막·자이언트·해골통·골렘·해골 무덤 1.4배, 인페르노 타워·테슬라(뇌전탑)·엘릭서 정제소 1.15배
- 대포 카트 바퀴가 한 덩어리로 같이 공전하던 것 → 바퀴 4개가 각자 제자리에서 굴러감 / 엘릭서 정제소 밸브가 엉뚱한 축으로 돌던 것 → 바퀴 가운데를 축으로 계속 돌아감
- 배틀 램 / 고블린 우리: 부서지는 모션이 끝난 뒤에 바바리안·고블린 브롤러가 나옴 (모션 겹침 수정)
- 자이언트 해골·폭탄 타워가 죽으면 떨어지는 폭탄을 자이언트 해골이 들고 있는 폭탄 크기로 (2배)
- 체력바가 모델 머리 위에 뜨게: 카드에 `bar-height` 가 없으면 모델 실제 키로 자동 계산 (자이언트 해골 등 체력바가 모델 속에 묻혀 안 보이던 문제)
- 메가 나이트 점프 / 도둑 대시: 타워·건물에는 벽 바로 앞까지만 달려듦 (안으로 파고들었다가 밀려나던 문제)
- 프린세스: 불화살 3발 (피해는 한 번, 맞은 자리에 불꽃)
- 얼음 마법사: 큰 눈덩이 대신 손에서 눈발을 뿌려 맞은 자리에 냉기 폭발 (손의 냉기도 덜 커지게)
- 얼음 골렘 1.8배, 타워 이름 「프린세스 타워」, 타워 위 프린세스 크기 줄임
- 탑뷰 이동 속도 빠르게 (`game.top-view.fly-speed`, 기본 0.35)
- 프린스 랜스가 몸에서 떨어져 보이던 것 수정 (손잡이-보호판-자루-창끝이 빈틈없이 이어지게 + 긴 랜스를 여러 본으로 나눔)
- 일렉트로 자이언트: 내리칠 때 손에서 대상까지 번개 + 스파크. 로얄 자이언트·일렉트로 자이언트 크기를 자이언트와 똑같이 (히트박스 [2.7, 4.8])
- **배치 시간 타이머**: 배치되는 동안 머리 위에 큰 타이머 판 (어두운 배경 + ⏱ 남은 초 + 진행 막대, 벽 너머로도 보임)
- **스턴 이펙트**: 스턴된 동안 머리 둘레로 노란 전기 별이 빙글빙글
- **체력바 길이 = 최대 체력**: 해골(81) 4칸, 미니언 6칸, 머스킷병 10칸, 기사 12칸, 자이언트·골렘 15칸 (최대 18칸)
- 로얄 자이언트 대포가 게임에서 몸과 떨어져 떠 있던 것 수정 (대포를 어깨에 고정하고 손으로 위를 잡음)
- 카드 아이템 개수로 엘릭서를 표시하던 것 제거 (1엘릭서 카드는 개수가 안 보여서 들쭉날쭉) → 모든 카드가 아이콘의 엘릭서 배지 + 이름 옆 💧 로 통일
- **플레이어가 유닛이 되면**: 플레이어 몸은 투명(입자 없음)하게 하고 카드 모델만 보이게, 손의 무기 아이템은 9번 칸으로 치움, **점프 불가** (효과는 1초마다 갱신돼서 유닛이 끝나면 바로 풀림)
- 이름: 페카 → **P.E.K.K.A**, 미니 페카 → **미니 P.E.K.K.A** (예전 config 이름도 자동으로 바뀜)
- 로비 카드 장식장: 볼러·도끼맨이 투사체(바위/도끼) 대신 본체 모델로 나옴
- **모델 작아진 채로 남는 버그 수정**: 소환 모션(작게 시작해서 커짐)이 중간에 끊기면 모델이 작은 채로 남던 문제 → 모든 모델의 기본/걷기/공격 모션이 크기를 1로 되돌림
- **도끼맨**: 도끼를 실제로 던짐 — 빙글빙글 도는 도끼 모델(`clash_executioner_axe`)이 갔다가 돌아오고, 날아가는 동안 손에는 도끼가 없음 (config `projectile-model`, 비우면 예전처럼 파티클)
- **도둑 은신**: 대시하는 동안 모습이 사라지고 보라 연기만 남음 (무적), 도착하면 나타나서 공격
- **가드 새 모델**: 원래 해골 병사 모델에 얼굴이 크게 트인 철모(팀색 장식) + 나무 방패 + 긴 창, 창으로 찌르는 공격 (방패 깨지면 방패 사라짐)
- 모션 수정: 창고블린(창을 머리 위로 들어 앞으로 던짐), 광부(삽을 머리 위로 휘둘러 앞쪽 땅을 내리침), 발키리(회전을 이펙트 속도에 맞춤), 사냥꾼(총구 불꽃 작게), 마법사(손의 불꽃은 공격할 때만)
- 모델: 프린스 새로 만듦 (돌격할 때 투구 눈 보호대를 내림, 말은 다크 프린스와 같음)
