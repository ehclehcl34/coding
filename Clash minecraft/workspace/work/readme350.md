## 3.5.0 — 새 카드 15장 / 배경음악 / 모델 멈춤 해결 / 타워 뒤 낑김 해결
### 모델이 소환 모션 첫 프레임에서 멈추던 문제 (확실히 해결)
- 원인 (BetterModel 소스 확인): BetterModel 은 모델을 보는 플레이어가 0명이 되는 순간 애니메이션 스케줄러를 끄는데,
  같은 순간 플레이어가 다시 보이기 시작하면 (텔레포트·추적 범위 들락날락) 스케줄러가 꺼진 채로 남음 → 처음 그린 프레임(소환 모션 1프레임)에서 굳음
- 해결: **0.5초마다 모든 모델 검사** → "보는 사람이 있는데 스케줄러가 꺼져 있음" 이 두 번 연속이면 그 모델을 새로 만들어 붙임 (팀색·숨긴 본 그대로)
  - 소환 모션이 5초 넘게 끝나지 않는 모델도 먼저 모션만 멈춰보고, 그래도 안 풀리면 새로 만듦
- 예전 "1.5초 뒤 spawn 강제 정지" 제거: 다른 애니메이션이 없을 때 강제로 멈추면 그 자리에서 굳는 원인이었음 (게다가 이름이 달라서 실제로는 아무것도 안 하고 있었음)
- 소환 모션(deploy)을 BetterModel 기본 idle 이 덮어서 안 보이던 것도 고침 → 이제 소환 모션이 제대로 보임

### 다리 5칸
- 다리 상판을 길과 같은 폭(3블록) + 양쪽 난간 = **5칸**으로 좁힘, 길과 일직선 (`preview/arena_3.5.0_bridge.png`)
- 유닛도 그 3블록 안으로만 건넘
- **경기장 schem 이 바뀌면 서버 켜질 때(자동 리로드 때) 비어 있는 경기장을 자동으로 다시 붙여넣음** (FAWE/WorldEdit 필요). 직접 손본 경기장이 있으면 config `arena-auto-repaste: false` 로 끄고 `/clash arena repaste`

### 타워 뒤에서 유닛이 낑기던 문제
- 겹침 방지가 유닛을 타워 밖으로 밀어내기만 해서, 타워 뒤에서 앞으로 가려던 유닛이 벽에 붙어 제자리 걸음
- 이제 가는 길을 타워·건물이 막고 있으면 **모서리를 돌아서** 감 (가장 짧은 쪽으로). 타워 옆에 붙여 지은 건물처럼 틈이 좁으면 하나로 보고 바깥으로 돌아감

### 로켓 더 크게
- 로켓 투사체 모델 약 1.6배 (3.4.x 대비), 발사 불꽃·연기도 크게 → `clash_rocket.bbmodel` 교체

### 모델 손질
- **자이언트 1.5배** (약 6블록, 히트박스 [2.7, 4.8]) — 기존 config 쓰면 `cards.giant.hitbox: [2.7, 4.8]` 로 고치기 (스킨 모델은 그대로 크기)
- 페카 1.2배 (히트박스 [1.7, 3.3]): 팔꿈치를 굽혀 앞으로 뻗은 주먹에 검을 수직으로 쥐고 위로 치켜세움, 공격은 어깨 위로 들었다가 내려찍기
- 자이언트 체력바가 머리 위에 뜨게 (`bar-height` 설정 추가: 체력바 높이를 카드마다 지정, 없으면 히트박스 높이)
- 기존 config 를 써도 **새 버전에 추가된 카드 설정 항목은 기본값으로 자동 채움** (bar-height, death-model 등)
- 배틀 램: 통나무 훨씬 크게 (굵기 약 2.5배 + 큰 쇠 머리), 감전돌이: 다리 → 바퀴, 대포 카트 1.35배, 고블린 싸움꾼 1.5배

### 배경음악 (직접 만든 곡, 리소스팩에 포함)
| 곡 | 언제 | 길이 |
|---|---|---|
| 로비 3곡 | 로비 | 류트·플루트 선술집 / 하프·리코더 왈츠 / 피치카토 장터 |
| 전투 3곡 | 경기 중 | 금관 영웅 테마 / 단조 전쟁 행진곡 / 바이올린 모험 지그 |
| 연장전 2곡 | 연장전 (서든데스) | 더 빠르고 긴장감 있는 단조 2곡 |
| 승리 / 패배 | 경기 끝날 때 한 번 | 5.6초 / 4.7초 |
- **곡마다 여러 버전** (로비 3곡 · 전투 3곡 · 연장전 2곡): 한 곡이 끝나면 다른 곡으로 바뀜
- **매칭 잡히고 시작 기다리는 동안(덱 확인 / 3초 대기)은 음악 꺼짐**
- 플레이어마다 따라다니며 재생, 리소스팩 적용이 끝나면 바로 처음부터
- **켜기/끄기**: 메인 메뉴 오른쪽 아래 **♫ 버튼** 또는 `/clash bgm` (또는 `/clash 음악`). 본인만 적용, 서버 재시작해도 유지 (`plugins/ClashMC/bgm_off.txt`)
- 소리 설정의 **"주크박스/소리 블록"** 음량을 따름 (`bgm.category` 로 MUSIC 등 변경 가능)
- config: `bgm.enabled / volume / lobby / battle / victory-defeat / length.*`

### 적용
1. `plugin/ClashMC-3.5.0.jar` 교체 (config.yml 은 안 바꿔도 새 카드가 기본값으로 들어감. 배경음악 설정을 바꾸려면 새 config 의 `bgm:` 부분 복사)
2. `models/base/*.bbmodel` 전부 → `plugins/BetterModel/models/` 덮어쓰기 (새 모델 20개 + 로켓 + 자이언트) → 서버 재시작 (또는 `/bettermodel reload` → `/cm reload`)
3. UI 팩(아이콘·음악)은 jar 안에 있어서 자동 배포 (합친 팩이 바뀌므로 접속자에게 한 번 새로 적용됨)
