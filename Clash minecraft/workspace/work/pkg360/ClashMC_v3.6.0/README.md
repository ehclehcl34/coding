# 클래시 마크 3.6.0

Paper 1.21.4 · BetterModel(추천) 또는 ModelEngine · FAWE/WorldEdit(경기장/로비 자동 붙여넣기용)

## 설치
1. `plugin/ClashMC-3.6.0.jar` → `plugins/` (기존 config.yml 은 백업 후 새 걸로 교체 권장)
2. 모델
   - **BetterModel**: `models/base/*.bbmodel`(77) → `plugins/BetterModel/models/` 바로 안에
   - (기본 모델 16개 → ModelEngine 무료판 12개 제한으로는 못 씀 → BetterModel 사용)
3. 리소스팩: 모델 플러그인(BetterModel)이 만든 팩은 서버 기본 팩으로 그대로 적용.
   **UI 팩은 2.9.0부터 플러그인이 알아서 배포** (jar 안에 들어 있음, 포트 8165) → 따로 합치거나 올릴 필요 없음
   (예전처럼 UI 팩을 기본 팩에 합쳐뒀다면 빼도 되고, 놔둬도 플러그인 팩이 위에 덮어씀)
   (또는 UI 팩을 따로 올리고 `ui.pack-url` / `ui.pack-sha1` 설정, sha1 = `2267f3f7e8ae470ed2a14a4d091d592d4a03b8ae`)
4. 서버 재시작 → 처음 켜면 `plugins/ClashMC/` 에 `clash_arena.schem`, `clash_lobby.schem`, `skins.yml` 생성
5. 로비: 로비 만들 자리에 서서 `/clash lobby paste`
6. 경기장: `/clash arena grid 4` (이미 있으면 `/clash arena repaste`) (서 있는 자리부터 +X 로 90블록 간격 4개) 또는 `/clash arena paste <이름>`
   - 직접 붙여넣었다면 기준점에 서서 `/clash arena add <이름>`
   - 경기장 개수 = 동시에 돌아가는 최대 경기 수

## 모드
| 모드 | 방법 | 내용 |
|---|---|---|
| AI 대전 | 메뉴 / 로비 초록 포털 / `/clash ai easy\|normal\|hard` | 봇 킹 상대. 친선전 방에서 시작하면 방 인원 전원이 한 팀 |
| 랭크전 | 메뉴 / 노란 포털 / `/clash ranked` | 비슷한 트로피끼리 2~10명(짝수) 자동 매칭, 트로피 변동 |
| 친선전 | 메뉴 / 파란 포털 / `/clash room ...` | 방 만들기 → 초대(클릭 수락) → 방장이 시작. 짝수 인원, 트로피 없음 |
| 테스트 | `/clash test start` (관리자) | 1인 테스트 + 치트 토글 |

## 트로피 / 티어
- 승리: 팀 전원 같은 양 획득 (상대 평균 트로피가 높을수록 많이, 3연승부터 보너스)
- 패배: **킹 ×1.3**, **유닛 ×0.5** (`ranked.king-loss-multiplier` / `unit-loss-multiplier`)
- **항복**: 전투 시작 60초 후부터 킹만 가능 (핫바 9번째 흰 깃발 두 번 우클릭 또는 `/clash ff`)
  → 진 팀은 **킹만 트로피 감소, 유닛은 0**
- 티어: 브론즈(0) · 실버(300) · 골드(700) · 플래티넘(1200) · 다이아몬드(1800) · 마스터(2500) · 그랜드마스터(3300) · 챔피언(4200), 티어마다 III/II/I
- 브론즈는 패배 감소 절반 보호

## 스킨
- 유닛 15종 × 3테마(서리 / 황금 / 그림자) + 프린세스/킹 타워 × 3테마(서리 / 황금 / 지옥불) = 51개
- 해금: 서리 = 최고 트로피 300, 황금 = 1200, 그림자 = 30승 / 타워: 700 · 1800 · 2500 (`skins.yml` 에서 수정)
- 적용: 킹이 고른 스킨으로 그 팀 유닛/타워가 나옴. 유닛으로 소환된 플레이어는 본인이 고른 스킨이 있으면 그걸로
- 관리자: `/clash giveskin <닉> <스킨id|all>`

## 로비 / 간편 메뉴
- 핫바: 플레이 · 덱 · 스킨 · (매칭 취소/방) · 랭킹 · 프로필 · 메뉴, **F키 = 메인 메뉴**
- 로비 schem: 성 안뜰, 포털 3개(밟거나 클릭), 동쪽 랭킹판(TOP10 홀로그램), 서쪽 스킨 전시대 4개(30초마다 교체, 회전), 남쪽 안내판, 분수
- 로비 스코어보드: 티어 · 트로피 · 다음 티어까지 · 서버 순위 · 전적 · 매칭/방 상태 · 진행 중 경기 수
- 로비 보호: 피해/허기/블록/아이템 이동 막힘 (크리에이티브 관리자는 예외)

## 2.0.1 수정
- **BetterModel 에서 대포/건물/타워/해골 비행선 모델이 안 보이던 문제**: BetterModel 은 바탕 엔티티가 투명이면 모델도 숨김 → 모델이 붙는 스탠드는 투명 해제 (숨김은 BetterModel 이 처리)

## 3.4.2 — 리소스팩은 최신 버전이 아닐 때만 다시 적용
- 예전엔 접속하면 월드에 들어온 뒤 게임 안에서 팩을 또 적용 → 들어갈 때마다 적용 화면
- 이제 플러그인이 **`server.properties` 에 합친 팩 주소·sha1·id 를 자동으로 적어둠** (`resource-pack`, `resource-pack-sha1`, `resource-pack-id`)
  → 접속할 때 **로딩 화면에서 한 번만** 적용, 같은 버전이면 클라이언트가 캐시에서 바로 씀 (다시 안 받음)
- 접속한 사람이 이미 최신 팩을 받았으면 게임 안에서 다시 안 보냄. **팩이 바뀌었을 때만** 새로 보냄 (같은 id 라 덮어씀, 안 쌓임)
- `/cm reload` 로 팩이 바뀌면: 지금 접속한 사람에겐 바로 새 팩 전송, server.properties 는 새 sha1 로 갱신 (다음 재시작부터 로딩 화면 적용).
  재시작 전까지는 예전 버전 주소로 와도 받을 수 있게 이번 세션 버전들을 보관
- **필요한 것**: `config.yml` → `ui.pack-host.address` 에 서버 주소 (예: `play.myserver.kr`) — 비어 있으면 server.properties 의 server-ip 사용, 둘 다 없으면 이 기능은 건너뜀 (콘솔 안내)
- 설정: `ui.pack-host.server-properties: true` (끄면 예전처럼 접속 후 전송)
- 참고: 서버를 나가면 마크 클라이언트가 서버 팩을 무조건 내림 (클라이언트 동작이라 플러그인으로 못 막음). 대신 다시 들어올 때 다운로드 없이 로딩 화면에서 바로 적용
- 적용: jar 교체 → config 에 address 넣기 → 재시작 **두 번** (첫 재시작 때 server.properties 에 등록, 두 번째부터 로딩 화면 적용)

## 3.0.1 — 프린스 돌진 / 겹침 방지
- **프린스 돌진 (원작대로)**
  - 2타일 쉬지 않고 달리면 돌진: 이동 속도 2배 + 다음 공격 784 (기존과 같음)
  - **멈추면 풀림**: 0.3초(`game.charge-reset-ticks: 6`) 이상 서 있으면 돌진/누적 거리 초기화
  - **넉백(통나무·파이어볼·눈덩이·로켓 등)에 맞아도 풀림** (스턴·빙결은 원래 풀렸음)
  - 돌진 시작할 때 말 울음 + 발굽 소리 + 먼지 연출 (경기장 전체에 들림)
  - 플레이어가 프린스일 때: 액션바에 `돌진 준비 ▮▮▮▯▯…` 게이지 → `⚡ 돌진! 다음 공격 784`, 돌진 중 먼지·크리티컬 파티클, 풀리면 `돌진 풀림`
- **유닛 · 건물 · 타워 안 겹침**
  - 유닛끼리 겹치면 서로 밀어냄 (지상끼리 / 공중끼리 따로). 큰 유닛이 작은 유닛을 더 많이 밀어냄 (골렘 > 자이언트 > 기사 > 고블린)
  - 지상 유닛은 타워·건물 사각형 안으로 못 들어감 (밖으로 밀려남). 정면으로 들이받으면 옆으로 미끄러져 돌아감
  - 플레이어 유닛도 밀림 (속도로 밀어서 텔레포트처럼 튀지 않음). `player-push: 0` 이면 플레이어는 안 밀림
  - 밀려도 강(다리 밖)이나 경기장 밖으로는 안 나감. 강 점프 중인 프린스/호그는 계산에서 뺌
  - 건물을 **타워나 다른 건물과 겹치는 자리에는 배치 불가** (`타워와 겹쳐서…` / `다른 건물과 겹쳐서…`). 봇도 같은 규칙
  - 건물/타워 사거리를 사각형 가장자리 기준으로 계산 → 근접 유닛이 타워 모서리에 밀려 못 때리는 일 없음
  - 설정 (`game.collision`): `enabled`, `strength`(0.5), `max-push`(0.35), `player-push`(0.5)
- 적용: **jar 만 교체 → 재시작**. 기존 config.yml 그대로 써도 기본값으로 켜짐 (설정 바꾸려면 위 `collision` 블록 복사)
- 모델 / UI 팩 변경 없음
- `source_3.0.1/` : 3.0.1 jar 에서 되살린 전체 소스 (기존 `source/` 폴더는 2.5.8 이라 오래됨). Battle / Combatant 는 이 소스로 다시 컴파일함

## 2.9.3 — 프린스 강 점프 / 타겟 / 반사경 표시

- 타겟: 유닛 · 타워 · 건물 모두 **항상 가장 가까운 적으로 바뀜** (한 번 끌렸다고 고정 안 됨, 0.6블록 이상 가까울 때만 바꿔서 왔다 갔다 방지)
  - 군단 AI 도 시야에 적이 있으면 가장 가까운 적, 없을 때만 우두머리가 때리는 대상을 따라감
- 반사경: 손에 든 카드가 **따라 할 카드 그림 + 반짝임**, 이름에 `반사경 → 카드 이름 N💧`, 설명에 실제 엘릭서 (그 카드 + 1)
  - 다음 카드 칸, 배치 미리보기(통나무 길 등)도 따라 할 카드 기준 / 팀 채팅에 `반사경 → 카드` 표시
- 미니언 패거리 카드 그림: 미니언 떼로 바꿈 (미니언 카드랑 구분)
- 적용: jar 교체 + config.yml 새 걸로 (또는 `prince` 에 `river-jump: true` 추가) + `clash_prince.bbmodel` 덮어쓰기 → 재시작

  - 자기 진영에만 사용, 앞으로 4.5타일 굴러가며 폭 2.6타일 안의 지상 유닛/건물에 230 피해 + 살짝 밀침
  - 크라운 타워는 피해 없음
  - 다 굴러가면 통이 깨지고 **바바리안 1명** (670 HP / 192 피해) 튀어나옴 — 대기열에 사람 있으면 그 사람이 바바리안
- 모델 `clash_barbarian_barrel`: 짧고 통통한 나무통(가운데 불룩) + 가시 박힌 양끝 쇠테 + 팀색 테 2줄 + 위에 꽂힌 칼, 뚜껑 구멍으로 바바리안이 얼굴 내밀고 주먹으로 테두리 잡고 있음 (통만 굴러가고 얼굴은 안 돔)
- 적용: jar 교체, **config.yml 새 걸로** (또는 `cards.barbarian_barrel` 블록 복사), bbmodel 추가, UI 팩 새로 (sha1 위에)

## 2.7.2 — 바바리안 망토 제거 / 엘바 투구 / 창 고블린 키
- 바바리안 · 엘리트 바바리안: 털 망토 없앰 (대신 가슴에 가죽 끈)
- 엘리트 바바리안 투구: 이마~눈~코만 가리고 하관(입·수염)은 보이게
- 창 고블린: 키 18% 키움 (히트박스 0.8 x 1.4) + 머리 20% 작게
- 적용: jar 교체, `clash_barbarian` / `clash_elite_barbarian` / `clash_spear_goblin` bbmodel 덮어쓰기, UI 팩 새로 (sha1 위에)
  기존 config 쓰면 `spear_goblins.hitbox: [0.8, 1.4]`

## 2.7.1 — 폭탄병 / 창 고블린 / 스피릿 아우라
- 폭탄병: 이마에 놋쇠 고글 (짙은 렌즈)
- 창 고블린: 창 더 길고 굵게 + 넓은 창날, 팀색 반다나 (뒤로 매듭 + 늘어진 끝)
- 스피릿 3종: 살아있는 동안 몸 주변에 계속 아우라
  - 아이스: 몸을 도는 하늘색 빛 고리 + 눈송이 + 발밑 서리
  - 파이어: 주황 빛 고리 + 머리 위 불꽃 + 작은 불씨 + 연기·용암 튐
  - 일렉트로: 하늘색 빛 고리 + 전기 불꽃 + 몸 주변 작은 번개 줄기 + 지지직 소리
- 적용: jar 교체, `clash_bomber` / `clash_spear_goblin` bbmodel 덮어쓰기, UI 팩 새로 (sha1 위에)

## 2.6.0 — 경기장 5개 / 경기 후 핫바
- 경기장 총 5개 자동 등록: 메인(main, 0 -60 0) 기준 +X 로 90칸마다 arena2~arena5 (x 90 / 180 / 270 / 360)
  - config 에 안 적어도 기본값으로 적용됨. 바꾸려면 `arena-grid.count` / `arena-grid.step`
  - 경기장 건물은 각 자리에 미리 붙여넣어져 있어야 함 (`/clash arena tp arena3` 로 확인)
- 수정: 경기 한 판 끝나고 로비로 돌아오면 핫바 아이템(플레이/덱/스킨/랭킹 등)이 안 생기던 문제
  - 원인: 경기에서 빠지기 전에 로비로 보내서 '아직 경기 중' 으로 판단 → 아이템 지급을 건너뜀

## 2.5.9 — 모델 다듬기
- 아처 / 머스킷병 모델 분리: `clash_rangers` 하나에 같이 들어 있던 걸 `clash_archer`, `clash_musketeer` 따로 (같이 보이던 문제 해결)

- 고블린: 멜빵끈 등쪽에도 추가
- 통나무: 굴러가는 거리 10.1블록, 폭 3.9블록 (기존 config 쓰면 `the_log.length: 10.1`)
- 적용: jar 교체, `plugins/BetterModel/models/` 에서 `clash_rangers.bbmodel` 지우고 새 bbmodel 전부 덮어쓰기
  기존 config 쓰면 `archers.model: clash_archer`, `musketeer.model: clash_musketeer` 로 고치기 → 서버 재시작
